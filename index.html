📁 Dự án của bạn

Dự án tự động lưu trong trình duyệt. Mở dự án nào thì làm tiếp dự án đó.

📋 Board GitHub Projects

App sẽ tạo 1 board “Video Affiliate” trên GitHub của bạn, có cột Trạng thái: Ý tưởng → Đang làm → Chờ xuất → Đã đăng. Mỗi video đưa lên board thành 1 thẻ. Mở board lên, bấm Board để xem dạng Kanban theo cột Trạng thái (GitHub không cho app tự tạo sẵn dạng Board, bạn bấm 1 lần là xong).

Chưa có board — bấm “Tạo board GitHub” (cần nhập token GitHub trong mục Kết nối trước).

Mở board trên GitHub ↗

🔌 Kết nối dịch vụ ngoài (API key)

Key chỉ lưu trong trình duyệt của bạn (localStorage), không gửi đi đâu ngoài API của chính dịch vụ đó khi bạn bấm dùng. Không bao giờ dán key vào chat hay gửi cho ai.

💡 Ghi chú: tên “Avid Lab” và “Zuno” là do bạn đọc bằng giọng nói — mình đoán là AI Lab (Videoslash) cho công cụ video và Suno cho nhạc nền. Nếu đoán sai, bạn sửa lại base URL trong ô bên dưới là dùng được đúng dịch vụ bạn muốn.

🎥 AI Lab — Videoslash

Công cụ video: upscale, lipsync, dịch video, reshoot. Cần gói đăng ký Videoslash đang hoạt động thì mới chạy được công cụ.

Chưa nối key.

🎵 Suno — nhạc nền

Suno chưa có API chính thức mở rộng, nên dùng qua nhà cung cấp bên thứ ba (gợi ý: TTAPI, APIMart, Kunavo). Nhập base URL của nhà cung cấp bạn dùng + key của họ.

Chưa nối key.

🖼️ OpenRouter — tạo ảnh

Tạo ảnh từ mô tả bằng model ảnh trên OpenRouter (mặc định: google/gemini-2.5-flash-image). Key của riêng bạn trên openrouter.ai.

Chưa nối key.

📷 Pexels — tìm ảnh stock

Tìm ảnh stock miễn phí trên Pexels. Key lấy miễn phí tại pexels.com/api (tạo tài khoản rồi bấm “Your API Key”).

Chưa nối key.

🐙 GitHub — tạo board Projects

Để app tự tạo board GitHub Projects và đưa video lên board, bạn cần Personal Access Token (classic) có quyền project. Tạo tại github.com → bấm ảnh đại diện → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → tick project → Generate token. Token chỉ lưu trong trình duyệt của bạn, chỉ gọi tới api.github.com khi bạn bấm dùng.

Chưa nối GitHub.

Bấm “Kiểm tra kết nối” để app gọi thử một yêu cầu nhẹ tới dịch vụ và báo đã nối hay chưa. Key tự lưu ngay khi bạn gõ xong.
